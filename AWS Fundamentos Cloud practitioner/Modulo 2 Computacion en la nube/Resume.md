|[Blog de informática de AWS](https://aws.amazon.com/blogs/compute/)|Este blog proporciona actualizaciones, tutoriales y prácticas recomendadas para utilizar los servicios informáticos de AWS, como Amazon EC2, AWS Lambda, Amazon ECS, etc.|
|[Servicios informáticos de AWS](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/compute-services.html)|Esta referencia proporciona una introducción en profundidad a los servicios informáticos disponibles en la nube de AWS.|
|[Tutoriales prácticos: Compute](https://aws.amazon.com/getting-started/hands-on/?awsf.getting-started-category=category%23compute&awsf.getting-started-content-type=content-type%23hands-on)|Este recurso proporciona tutoriales prácticos paso a paso diseñados para ayudar a los usuarios a adquirir experiencia práctica con los servicios informáticos de AWS. Es ideal para principiantes y para quienes se inician en la computación en la nube.|
|[Amazon EC2](https://aws.amazon.com/ec2/)|Amazon EC2 ejecuta servidores virtuales en la nube con capacidad informática flexible.|
|[Tipos de instancias de Amazon EC2](https://aws.amazon.com/ec2/instance-types/)|Esta guía proporciona información detallada sobre los diferentes tipos de instancias EC2, incluidas sus especificaciones, capacidades y casos de uso. Le ayuda a elegir el tipo de instancia adecuado en función de sus necesidades de carga de trabajo, como los requisitos de computación, memoria y almacenamiento.|
|[Precios de Amazon EC2](https://aws.amazon.com/ec2/pricing/)|En esta guía se explican los diferentes modelos de precios de las instancias de EC2, incluidas las instancias bajo demanda, las instancias reservadas y las instancias puntuales, para que pueda elegir la mejor opción en función de su uso.|
|[Autoescalado de Amazon EC2](https://aws.amazon.com/ec2/autoscaling/)|Amazon EC2 Auto Scaling ajusta automáticamente el número de instancias en función de la demanda para ofrecer alta disponibilidad y rentabilidad.|
|[Balanceador de cargas elástico](https://aws.amazon.com/elasticloadbalancing/)|Elastic Load Balancing distribuye automáticamente el tráfico entrante de las aplicaciones entre varias instancias de EC2 para ofrecer alta disponibilidad y tolerancia a las fallas.|
|[Servicio de notificación simple de Amazon](https://aws.amazon.com/sns/)|Amazon SNS es un servicio de mensajería para enviar notificaciones a usuarios u otras aplicaciones a través de SMS, email o notificaciones push móviles.|
|[Servicio de cola de Amazon Simple](https://aws.amazon.com/sqs/)|Amazon SQS desacopla los componentes de la aplicación mediante colas de mensajes, almacenando y procesando mensajes de forma fiable.|
